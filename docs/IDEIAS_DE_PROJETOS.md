# Ideias de projetos didáticos em C#

**Não há ideias pendentes.** Todas as propostas desta lista foram implementadas, das 13 trilhas temáticas — `01-Fundamentals` a `13-SDKsAndLibraries`.

Esta lista propunha novos samples alinhados às trilhas do repositório, cada item explicitando o principal aprendizado esperado sem repetir o foco central dos exemplos já catalogados. Ideias implementadas saíam da lista conforme os projetos entravam no catálogo.

Para ver o que existe hoje, consulte o **Índice Completo de Projetos** no [README raiz](../README.md). Para propor um sample novo, acrescente uma seção da trilha correspondente abaixo, no mesmo formato de tabela, e siga o fluxo de [`.github/skills/create-csharp-project-by-task/SKILL.md`](../.github/skills/create-csharp-project-by-task/SKILL.md).

```markdown
## NN-NomeDaTrilha

| # | Projeto sugerido | Finalidade didática |
|---:|---|---|
| 1 | `NomeDoProjeto` | O que o exemplo deve ensinar, em uma frase. |
```

## Critérios usados na seleção

- Complementar os projetos existentes em vez de recriar seus exemplos centrais.
- Manter cada sample focado em um conceito principal e executável de forma independente.
- Misturar fundamentos, práticas de produção e tópicos avançados em uma progressão de aprendizado.
- Priorizar lacunas nas trilhas com menor quantidade de projetos.
